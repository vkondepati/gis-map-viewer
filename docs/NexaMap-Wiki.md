# NexaMap Wiki

Welcome to the NexaMap project wiki.

NexaMap is an open-source GIS platform focused on accessible geospatial learning, spatial analytics, and AI-ready GIS workflows.

---

# 🌍 Vision

The mission of NexaMap is to democratize GIS education and spatial technology by creating a lightweight, offline-first, AI-ready GIS ecosystem.

We aim to make geospatial learning accessible for:

- Students
- Educators
- Researchers
- Developers
- Open-source communities
- Low-bandwidth and underserved regions

---

# 🚀 Core Features

## 🗺️ Interactive GIS Mapping

- Layer management
- Feature inspection
- Zoom & pan
- Spatial navigation
- Thematic visualization

## 📊 Spatial Analysis

- Buffer analysis
- Distance calculations
- Spatial overlays
- Geometry editing
- Intersection operations

## 📂 Data Format Support

Supported formats include:

- GeoJSON
- Shapefile
- KML
- GeoPackage
- CSV
- MBTiles

## ☁️ Modern Data Integrations

NexaMap integrates with modern cloud-native data platforms:

- DuckDB
- Snowflake
- Databricks
- Apache Iceberg

## 🤖 AI-Ready Architecture

Planned GeoAI capabilities include:

- AI GIS assistants
- Natural language spatial queries
- Agentic GIS workflows
- AI-assisted spatial analysis

# 🏗️ Architecture

NexaMap uses a modular architecture built with:

- Electron
- React
- TypeScript
- Shared GIS rendering engine
- Web and desktop adapters

The architecture is designed for extensibility and future plugin support.
